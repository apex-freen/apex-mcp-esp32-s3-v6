# 立创实战派（LCKFB 实战派）ESP32-S3 项目分析

> 基于 `szpi-s3-esp` 目录梳理。该目录是立创开源硬件平台「实战派」开发板的官方示例集合，全部基于 ESP-IDF 构建。

---

## 一、项目定位

- **平台**：ESP32-S3（双核 Xtensa LX7，带 PSRAM），Flash 大小 16MB（见各示例 `sdkconfig.defaults`：`CONFIG_ESPTOOLPY_FLASHSIZE_16MB=y`）
- **性质**：官方入门例程，共 **14 个示例**，按编号递增从基础（按键）到综合（手持机），用于演示板载全部硬件外设
- **形式**：每个示例都是一个**独立、完整、可单独编译烧录**的 ESP-IDF 工程，目录间无相互依赖，仅共享同一份板级驱动源码（`esp32_s3_szp.c/h`，各目录内各自拷贝一份）

---

## 二、整体架构

### 2.1 目录结构

```
szpi-s3-esp/
├── 01-boot_key/            按键输入（GPIO 中断）
├── 02-attitude/            姿态传感器（QMI8658 六轴 IMU）
├── 03-micro_sd/            SD 卡读写
├── 04-audio_es7210/        音频 ADC 录音（ES7210，4 通道）
├── 05-audio_es8311/        音频 DAC 播放（ES8311）
├── 06-lcd/                 LCD 显示（ST7789，SPI）
├── 07-lcd_camera/          LCD + 摄像头实时显示（OV2640）
├── 08-lcd_lvgl/            LVGL 图形库 + 触摸屏
├── 09-wifi_scan_connect/   WiFi 扫描/连接 + LVGL UI
├── 10-ble_hid_device/      BLE HID 键盘设备
├── 11-mp3_player/          MP3 播放器（SPIFFS + codec）
├── 12-speech_recognition/  离线语音识别（esp-sr）
├── 13-human_face_detection/ 人脸检测（esp-dl，C++）
└── 14-handheld/            综合手持设备（整合全部功能）
```

### 2.2 分层模型

```
┌─────────────────────────────────────────────┐
│ 应用层  main.c / app_ui.c / app_sr.c / ...  │  ← 业务逻辑、UI、任务编排
├─────────────────────────────────────────────┤
│ BSP 层  esp32_s3_szp.c / esp32_s3_szp.h     │  ← 板级驱动（唯一核心复用文件）
│         I2C / QMI8658 / PCA9557 / LCD       │
│         摄像头 / I2S音频 / 触摸 / LVGL / SPIFFS│
├─────────────────────────────────────────────┤
│ 组件层  espressif 官方组件（组件管理器拉取）    │  ← esp_lcd / lvgl / camera /
│         esp_codec_dev / esp-sr / esp-dl 等   │     codec / ft5x06 等
├─────────────────────────────────────────────┤
│ 系统层  ESP-IDF（FreeRTOS / 驱动 / 网络栈）    │
├─────────────────────────────────────────────┤
│ 硬件层  ESP32-S3 + 板载外设                    │
└─────────────────────────────────────────────┘
```

### 2.3 核心设计要点

1. **BSP 文件即"板卡手册"**：`esp32_s3_szp.h` 以宏形式集中定义了全部引脚、外设地址、寄存器，`esp32_s3_szp.c` 提供驱动函数。各示例按需裁剪（如 `02-attitude` 只保留 I2C + QMI8658，`07-lcd_camera` 增加 PCA9557/LCD/摄像头）。
2. **工程构建**：每个工程根 `CMakeLists.txt` 只做标准 `project(...)`，源码清单在 `main/CMakeLists.txt` 中用 `idf_component_register(SRCS ...)` 声明。
3. **依赖管理**：通过 `main/idf_component.yml` 引入乐鑫官方组件（版本固定），未使用本地私有组件（唯一例外是 13 号示例在 `components/` 下内嵌了完整的 esp-dl 源码）。
4. **多任务并发模式**：
   - 摄像头→LCD 显示采用 **FreeRTOS 队列 + 双核固定任务**（采集任务绑 Core1，显示任务绑 Core0）；
   - 人脸检测在中间插入 AI 推理任务（采集→AI→显示 三段流水线）；
   - `14-handheld` 使用**事件组**（`xEventGroupWaitBits`）实现开机音乐播放完再进主界面的同步。
5. **大块缓冲放 PSRAM**：LCD 整屏/整行缓冲、摄像头帧缓冲（`fb_location = CAMERA_FB_IN_PSRAM`）均显式分配在外部 PSRAM，避免挤占内部 DRAM。
6. **分区表**：涉及大容量数据（WiFi 固件、AI 模型、MP3、语音模型）的工程使用 `partitions.csv`，`factory` 分区扩至 7MB；小工程直接用默认分区。

## 三、GPIO 接口内容（有，且完整）

板级驱动中**有完整、明确的 GPIO 定义**，集中在各示例的 [esp32_s3_szp.h](file:///e:/esp32/apex-mcp-esp32-s3-v6/apex-mcp-esp32-s3-v6_szpi/szpi-s3-esp/07-lcd_camera/main/esp32_s3_szp.h) 中，覆盖全部板载外设。汇总如下：

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| BOOT 按键 | GPIO0 | 输入 + 内部上拉，下降沿中断 |
| **I2C0** | SDA=GPIO1, SCL=GPIO2 | 100kHz 主模式，总线复用（IMU/IO扩展/摄像头 SCCB） |
| QMI8658 六轴 IMU | I2C 地址 0x6A | 加速度 + 陀螺仪，寄存器驱动 |
| PCA9557 IO 扩展 | I2C 地址 0x19 | 见下方 3 路扩展 IO |
| SD 卡（SDMMC） | CLK=47, CMD=48, D0=21 | 1 线模式，内部上拉 |
| I2S0 音频 | MCK=38, BCK=14, WS=13, DO=45 | 播放走 ES8311（DAC），录音走 ES7210（ADC，DI 复用） |
| LCD（ST7789） | MOSI=40, SCLK=41, DC=39, 背光=42 | SPI3 主机，80MHz 像素时钟，16bit RGB565 |
| LCD CS | PCA9557 IO0（`BIT(0)`） | 片选由 IO 扩展芯片控制 |
| 功放使能 PA_EN | PCA9557 IO1（`BIT(1)`） | 音频功放电源开关 |
| 摄像头电源 DVP_PWDN | PCA9557 IO2（`BIT(2)`） | 上电默认 1（关） |
| 触摸 FT5x06 | I2C（复用 GPIO1/2） | RST/INT 均接 NC |
| 摄像头 OV2640（8bit DVP） | XCLK=5, PCLK=7, VSYNC=3, HREF=46 | |
|  | D0=16, D1=18, D2=8, D3=17 | |
|  | D4=15, D5=6, D6=4, D7=9 | |
|  | SCCB：SDA=1, SCL=2（复用 I2C0） | XCLK 24MHz，帧缓冲放 PSRAM |

> PCA9557 控制方式：`pca9557_init()` 写输出寄存器（默认 `0x05`：DVP_PWDN=1、PA_EN=0、LCD_CS=1），配置寄存器 `0xf8` 将 IO0~IO2 设为输出；随后通过 `lcd_cs()/pa_en()/dvp_pwdn()` 按位读写电平。

GPIO 定义示例（节选自 `07-lcd_camera`）：

```c
#define BSP_I2C_SDA           (GPIO_NUM_1)   // SDA引脚
#define BSP_I2C_SCL           (GPIO_NUM_2)   // SCL引脚
#define BSP_LCD_SPI_MOSI      (GPIO_NUM_40)
#define BSP_LCD_SPI_CLK       (GPIO_NUM_41)
#define BSP_LCD_DC            (GPIO_NUM_39)
#define BSP_LCD_BACKLIGHT     (GPIO_NUM_42)
#define CAMERA_PIN_D7 9  ...  // 摄像头数据线等
```

## 六、对本项目的可借鉴点

1. **BSP 集中管理引脚**：所有 GPIO/外设地址收敛到单个头文件，换板只需改宏，可作为硬件抽象层范本。
2. **示例分级递进**：从点灯按键 → 外设单项 → 组合（LCD+Camera）→ 集成（LVGL/网络/AI）→ 综合产品，是优秀的教学/演示代码组织方式。
3. **多核流水线**：摄像头采集、AI 推理、LCD 渲染分别绑定不同核心，用队列解耦，对 MCP/智能体类高吞吐应用同样适用。
4. **依赖用组件管理器**：`idf_component.yml` 锁定版本，工程间零拷贝复用官方组件。
