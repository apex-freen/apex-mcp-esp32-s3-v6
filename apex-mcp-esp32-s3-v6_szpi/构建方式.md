构建方式
Bash
运行
# 联调（明文可见）
idf.py -DSDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.defaults.debug" build

# 量产（明文裁剪）
idf.py build
⚠️ 若工程已存在旧 sdkconfig，需先删除它（或 idf.py set-defaults sdkconfig.defaults），新配置才生效。


构建时注意
删除旧 sdkconfig 让 PSRAM 配置生效：rm sdkconfig 或 idf.py set-defaults sdkconfig.defaults
内存预算：新增静态缓冲 12KB 内部 RAM（M3 命令队列还会加 ~16KB，到时候再评估）
验证：跑起来后看 APEX_MONITOR 日志的 DRAM/PSRAM 行；连续下 100 次指令看"历史最小堆"是否稳定
